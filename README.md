One image that sums up the world's news of **Saturday 21 November 2026**:
46 stories across 7 regions, each with the source that reported it that day,
a UTC timeline strip across the day, a world map with numbered dots matching
the stories, and a DATE CHECK box listing the big stories deliberately left
out because they happened on another day.

## What's in the image

- **46 stories, 7 regions** — North America, Europe, Middle East, South Asia,
  East Asia / Pacific, Africa, Latin America.
- **Top stories** — NATO jets scrambled after a Russian missile lands in
  Poland; US stocks plunge (Nasdaq −5.3%, S&P −3.7%); COP31 talks run into
  overtime in Antalya; Bolsonaro taken to hospital in Brasilia; Trump weighs
  new Iran strikes; Cyclone Akvan's aftermath in Odisha; Sensex +898.
- **UTC timeline** — the day as it was reported, 00:30 to Saturday evening.
- **Numbered world map** — every dot is a story number in the list.
- **Date check** — ICJ Myanmar verdict (19 Nov), Trump–Xi–Putin summit
  (19 Nov), Anthropic IPO debut (19 Nov), Cyclone Akvan landfall (20 Nov),
  UK–EU summit deals (20 Nov) and the Poland missile impact (overnight
  20 Nov) are NOT presented as 21 November news.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png`. The program runs twice and
writes the same bytes both times — verified locally, both runs produced
the identical 1024 × 1024 PNG (242,550 bytes). No network is used.
